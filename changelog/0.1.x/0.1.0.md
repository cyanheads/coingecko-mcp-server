# 0.1.0 — 2026-06-13

Cryptocurrency market data via the live CoinGecko v3 REST API. Read-only, keyless by default; an optional `COINGECKO_API_KEY` attaches the Demo-tier header for a higher rate ceiling.

## Added

- **`coingecko_search_coins`** — resolve a name or ticker to a CoinGecko slug (ranked candidates with `market_cap_rank`). The required first step before any ID-keyed tool.
- **`coingecko_get_prices`** — batch current price and core stats for up to 250 slugs across multiple currencies. Diffs requested-vs-returned ids into a `missing` field (a bad slug is a silent `200 {}` upstream, not an error); throws `all_missing` only on a total miss.
- **`coingecko_list_markets`** — ranked market table by market cap, volume, or 24h change, optionally filtered to a category. Detects an unrecognized category (upstream returns empty) and maps it to `unknown_category`.
- **`coingecko_get_coin`** — deep single-coin profile (description, categories, links, market data, developer activity, community, sentiment) with a `sections` selector to trim the large record.
- **`coingecko_get_market_chart`** — historical price/market-cap/volume series in `recent` (last N days, auto-granularity) or `range` (explicit Unix-second window) mode. Timestamps are milliseconds.
- **`coingecko_get_trending`** — coins trending by 24h search volume; surfaces only trustworthy numerics (price float, USD 24h change), dropping upstream's pre-formatted display strings.
- **`coingecko_get_global`** — global market snapshot: total market cap and volume, BTC/ETH dominance, active-coin/market counts, ongoing ICOs, and 24h change.
- **`coingecko_list_categories`** — coin categories (`category_id` + display name) with a local `name_contains` token filter over the full ~800-entry list; feeds the `category` param of `coingecko_list_markets`.
- **`coingecko://coin/{id}`** and **`coingecko://global`** resources mirroring `coingecko_get_coin` and `coingecko_get_global`.
- **`coingecko_coin_research`** prompt — guides the search → get_coin → get_market_chart → get_global research chain.
- **`COINGECKO_API_KEY`** optional env var (`x-cg-demo-api-key` header). Keyless by default; base URL unchanged either way.
- **`coingecko` service** — one method per endpoint, each wrapping fetch + parse in `withRetry` (429/5xx/timeout retried with calibrated backoff); 404 surfaces as a typed `coin_not_found`. Every tool output carries CoinGecko attribution.

## Removed

- Echo scaffold tool, app-tool, resource, app-resource, and prompt (and their tests) from the `init` template.
