# 0.1.4 — 2026-10-07

## Changed

- **Tool error recovery** relies on declared hints instead of redundant throw-site forwards; contract tests cover all six handler failures. The framework fills hints and error `data.requestId` from 0.13.10, with generated request IDs and client `jsonRpcId` separation from 0.13.12.
- **String inputs** accept safe integers through framework repair introduced in 0.13.9; the advertised schemas stay unchanged.
- **Docker dependencies** cross-install natively in a `BUILDPLATFORM` stage, using the configured scanner and framework OpenTelemetry peer ranges, then prune musl-only packages before the glibc runtime image.
- **Packaging exclusions** keep `dist/*.mcpb` out of npm and local cache, logs, and design notes out of desktop bundles; environment files and registry tokens are excluded from container contexts.
- **Development tooling** and framework skills are synced, including MCP import failures, packaging validation, portable git scans, tag validation, and per-language CodeQL categories. `.env.example` documents current opt-in logging and telemetry settings.

## Fixed

- **Registry npm entries** invoke the package bin with `npx`; the HTTP entry fixes `MCP_TRANSPORT_TYPE=http` instead of passing npm-script arguments.
