# 0.1.2 — 2026-08-21

## Changed

- **Framework** `@cyanheads/mcp-ts-core` ^0.10.6 → ^0.12.3 (MCP SDK v2). Protocol revision 2026-07-28 is served alongside the 2025 era; tool inputs are strict, so an unknown argument key is rejected by name; the advertised `outputSchema` declares the error envelope; input-validation failures read as flat `path: message` sentences; `ctx.log` lines also reach clients as `notifications/message`.
- **Rate-limit backoff honors upstream `Retry-After`**, and expected non-2xx statuses log at debug instead of error (`expectedStatuses`).
- **Docker image** builds on bun 1.4.0 with BuildKit cache mounts and `--omit=peer` production installs; the build stage is pinned to `$BUILDPLATFORM`, so `linux/amd64` images build natively instead of under QEMU emulation.
- **`websiteUrl` dropped from `createApp()`** — server identity is `name` + `title`; description derives from `package.json`.

## Fixed

- **`unsupported_currency` and `unknown_category` return `NotFound` (-32001)** instead of `InvalidParams` (-32602) — an unrecognized currency or category slug is a missing resource, not a malformed argument.
- **`invalid_range` returns `ValidationError` (-32007)** instead of `InvalidParams`, matching the framework's baseline classification.

## Added

- **Supply-chain guard**: installs reject packages published less than 3 days ago (`minimumReleaseAge`; the first-party framework is excluded), and every install is scanned by the Socket security scanner.
- **Community health files**: CONTRIBUTING.md, CODE_OF_CONDUCT.md, SECURITY.md, FUNDING.yml.
