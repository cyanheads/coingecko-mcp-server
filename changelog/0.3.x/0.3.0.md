# 0.3.0 — 2026-11-20

## Added

- **`coingecko_search_coins` and `coingecko_get_coin`** resolve a platform and contract address to a coin ID and expose the coin’s contracts in the `platforms` section. ([#14](https://github.com/cyanheads/coingecko-mcp-server/issues/14))
- **`coingecko_list_categories`** ranks and pages categories by market data, with market cap, 24-hour change and volume, update time, and top coin IDs. ([#24](https://github.com/cyanheads/coingecko-mcp-server/issues/24))
- **`coingecko_get_global` and `coingecko://global`** expose the full dominance map and include Fear & Greed when CoinGecko supplies the value and sentiment. ([#23](https://github.com/cyanheads/coingecko-mcp-server/issues/23))
- **`skill://coingecko-guide/SKILL.md`** provides a discoverable guide to choosing tools and chaining coin lookups, market data, and history.

## Changed

- **Global metrics** can omit unavailable numeric fields in `coingecko_get_global` and `coingecko://global`. Clients that require numeric values must handle their absence. ([#23](https://github.com/cyanheads/coingecko-mcp-server/issues/23))
- **Plugin and bundle packaging** includes root plugin configuration and ships the CoinGecko guide with npm, MCPB, and Docker.

## Fixed

- **`coingecko_get_prices`** reports each coin’s quote timestamp when available and uses the oldest returned timestamp for the batch. ([#18](https://github.com/cyanheads/coingecko-mcp-server/issues/18))
- **`coingecko_get_market_chart`** reports the applied window and identifies inputs it ignored when lookback and explicit-range fields are mixed. ([#19](https://github.com/cyanheads/coingecko-mcp-server/issues/19))
- **`coingecko_get_prices` and `coingecko_list_markets`** split comma-delimited IDs. Price lookups also split comma-delimited currencies. ([#20](https://github.com/cyanheads/coingecko-mcp-server/issues/20))
- **`coingecko_list_categories`** matches prefixes at the start of category words. ([#21](https://github.com/cyanheads/coingecko-mcp-server/issues/21))
- **`coingecko_list_markets`** reports missing IDs when a short first page establishes which requested coins have no market row. ([#22](https://github.com/cyanheads/coingecko-mcp-server/issues/22))
